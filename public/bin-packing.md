# ТЗ: оптимальная укладка кирпичей в прямоугольную коробку (3D)

**Задача** — заполнить коробку (прямоугольный объём \( L \times W \times H \), например, фундамент или каркас), а не плоскую стену. Из визуала: 3D-распределение — углы/рёбра **красные C**, середина граней — **жёлтые H/S**, внутренняя заливка — **коричневые S**. Это обобщение на **3D Brick Packing with Constraints** — NP-полная (сводится к 3D Bin Packing).

---

## 1. Постановка задачи (3D)

Дана **коробка** размером \( L \times W \times H \) (длина × ширина × высота). Кирпичи укладываются горизонтальными слоями (по высоте \( H \)):

- Каждый слой — сетка \( W \times L \) (как 2D-стена из прошлого ТЗ).
- 6 граней коробки имеют ограничения (углы, края).
- Внутренний объём: свободная заливка S.

**Типы кирпичей** (те же):

- **S (стандартный):** длина \( x \), везде (включая внутренность).
- **H (половина):** длина \( x/2 \), только строгая середина граней (расстояние \( \geq x \) от любого ребра/угла).
- **C (замыкающий):** длина \( [x,\ 2x] \), только углы и рёбра граней (4 угла + края на грань).

**Цель:** Минимальное

\[
N = N_S + N_H + N_C
\]

для полного заполнения объёма без зазоров.

**NP-трудность:** 3D-комбинаторика × экспонента по слоям; требуется DP по слоям + 2D-оптимизация граней.

---

## 2. Входные данные

- **L, W, H:** размеры коробки (целые, \( 1 \leq L,\, W \leq 500 \); \( H \leq 50 \)).
- **x:** базовая длина кирпича (\( 0{,}1 \leq x \leq 10 \)).

*Пример из скриншота* (~5×5×3, \( x \approx 1 \)): углы C (красные), H (жёлтые) в центре граней.

---

## 3. Ограничения размещения (3D / скриншот)

Для каждой грани слоя (4 боковые + 2 торцевые):

- **Углы (4 на грань):** только C, длина в \( [x,\ 2x] \).
- **Рёбра (между углами):** C или S.
- **Середина грани:** только H или S (строго \( > x \) от краёв).
- **Внутренность слоя** (если \( L,\, W > 2x \)): только S.
- **По высоте:** каждый уровень \( H \) — идентичен или варьируется (оптимизировать независимо).

*Из скриншота:*

- Красные: C в углах и на рёбрах.
- Жёлтые: H в серединах граней.
- Коричневые/зелёные: S внутри + заливка.
- Полное покрытие без «дыр».

---

## 4. Выход калькулятора

- Минимальное \( N \), разбивка: \( N_S \), \( N_H \), \( N_C \).
- **Визуализация:** 3D-модель (как на скрине).
- По слоям: грани (C–H–S–H–C), рёбра (C–S–C), внутренность (S S S …).
- **Экономия** в % по сравнению со сплошной заливкой S.
- **Экспорт:** JSON конфигурации + STL для 3D-печати/визуала (Three.js).

*Пример вывода:*

```
Минимальное N: 150
N_S=100, N_H=30, N_C=20
Слой 1 (нижний):
  Грани: C-H-S-H-C | рёбра: C-S-C
  Внутрь: S S S
...
Экономия: 25% vs все S (N=200).
```

---

## 5. Алгоритм реализации

- **Точное** (малые размеры):
  - Для каждого слоя \( h = 1 \ldots H \): рекурсивно оптимизировать 4 грани + внутренность.
  - DP[state]: мин. кирпичи для слоёв с состоянием (остатки).
- **Приближённое:** Genetic Algorithm — мутации шаблонов граней.
- **Визуал:** Three.js — рендер коробки с цветами (красный = C, жёлтый = H, коричневый = S).

---

## 6. Прототип-код (JS, 3D-коробка)

Нижняя оценка числа кирпичей; для точного решения — генератор шаблонов граней (расширение `minBricksForRow` на 2D-рамку).

```javascript
function minBricksBox(L, W, H, x) {
  // Мин. кирпичей на один слой (грани + внутренняя сетка)
  function minLayer(w, l) {
    const edgeMin = Math.ceil((w - 2 * x) / (x / 2)) + 2  // C + H/S + C
    const innerW = Math.max(0, w - 2 * x)
    const innerL = Math.max(0, l - 2 * x)
    const innerBricks = Math.ceil(innerW / x) * Math.ceil(innerL / x)
    return 4 * edgeMin + innerBricks  // 4 грани + внутр.
  }

  return H * minLayer(W, L)
}

// Тест для ~скриншота 5×5×3, x=1
console.log(minBricksBox(5, 5, 3, 1))  // ~45–60 кирпичей
```
