# Калькулятор кирпичей для стен дома

Vue 3 приложение для оценки количества кирпичей при строительстве стен дома по заданным размерам фундамента, кирпича и количеству рядов.

## Возможности

- **Левая панель**: размеры дома (длина, ширина в м), размеры кирпича (мм), количество рядов
- **Центр**: Canvas-визуализация прямоугольника фундамента с кирпичами по периметру
- **Правая панель**: сводка параметров
- **Нижняя панель**: таблица расчётов (кирпичей в ряду, рядов, общее количество, высота стен)

## Формулы расчёта

- Периметр: `P = 2 × (длина + ширина)` м
- Кирпичей в ряду: `X = ceil(P / (ширина_кирпича_мм / 1000))`
- Общее количество: `X × рядов`
- Высота стен: `ряды × (высота_кирпича_мм / 1000)` м

## Стек

- Vue 3 (Composition API)
- Vite
- PrimeVue (Slider, InputNumber)

## Установка и запуск

```bash
npm install
npm run dev
```
